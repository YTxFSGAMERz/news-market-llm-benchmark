# Preregistration checklist

Complete and commit this document before inspecting final test results.

- [ ] Define eligible exchanges, ticker universe and sample period.
- [ ] Define source list and licensing/redistribution constraints.
- [ ] Define timestamp handling, duplicate detection and ticker mapping.
- [ ] Define primary outcome and return horizon.
- [ ] Define benchmark index and market-model estimation/event windows.
- [ ] Define chronological train, validation and test boundaries.
- [ ] Freeze model identifiers, prompts, parameters and retry rules.
- [ ] Define missing-data and low-confidence handling.
- [ ] Select primary metrics and statistical tests.
- [ ] Define clustering / dependence treatment and multiple-testing correction.
- [ ] Define robustness checks and subgroup analyses.
- [ ] Record all deviations from this protocol with dates and reasons.

Do not fill this checklist retrospectively to make results look preplanned.
